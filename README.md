# Matchday Eleven

An original 11v11 football simulation for **Android arm64**, built with **Godot 4.5.2-stable**.
eFootball-style on-screen controls, full match rules (set pieces, fouls, cards, offside,
substitutions), team AI, procedural stadium — every asset in the game is **generated by
`tools/gen_assets.py`**, nothing is ripped or licensed from anyone.

**One command build:** `bash build/export.sh` → `build/matchday-eleven-arm64.apk`

## Controls (touch)

| Input | Action |
| --- | --- |
| Left thumb | Floating virtual joystick (appears where you touch, drags with you) |
| SHOOT | Hold to charge (power bar + ring arc), release to shoot |
| PASS | Short pass, stick-direction bias |
| THRU | Through ball into space |
| LOB | Lofted pass / cross into the box |
| SPR | Sprint (hold); pushing the stick to the edge also sprints |
| TACKLE / PRESSURE | Contextual: slide tackle when defending, press when loose |

Multi-touch is fully independent per finger (joystick + buttons simultaneously),
actions fire directly in `_input()` (no polling latency), haptic feedback on button
press. Button size, opacity, left/right-handed layout and haptics are adjustable in
the menu and persist in `user://controls.cfg`. Desktop testing: WASD + J/SPACE/K/L/I/U.

## Gameplay

- 11 v 11, two halves of configurable length, half-time and full-time states.
- Formations 4-4-2 / 4-3-3 / 3-5-2 with role-based anchors, stamina, pressing,
  marking, passing-lane evaluation and off-ball runs.
- Ball: gravity, drag, Magnus spin curve, bounce restitution, rolling friction,
  post/crossbar deflection.
- Set pieces: kick-off, throw-in, corner, goal kick, free kick, penalty.
- Referee: tackle foul decisions, yellow/red cards, offside approximation.
- Goalkeeper AI: positioning on the ball-goal line, dives, claims, distribution.
- HUD: scoreboard, clock, event banners, charge bar, radar minimap, cards, replay.

## Engine-side tests

```
godot --headless -s tests/run_tests.gd
```
51 checks: ball physics (settle, friction, bounce, curve, post deflection), match
state (halves, clock, out-of-play rules), formations (3 shapes, mirroring), referee
(fouls, cards), offside line, input mapping (hit-testing, joystick, multi-touch,
settings persistence) and a full match smoke test (kick-off → play → throw-in →
goal → celebration → half time → full time).

## Build

| Pin | Value |
| --- | --- |
| Godot editor | 4.5.2-stable (Linux x86_64) |
| Export templates | 4.5.2-stable |
| ABI | arm64-v8a only |
| Signing | `signing/debug.keystore` (public project key, user `androiddebugkey`, password `android`) |

`build/export.sh` downloads the pinned engine (cached), generates assets when absent
(deterministic, seeded), runs the tests and exports the APK. CI (`.github/workflows/build.yml`)
runs the same script on `ubuntu-latest` with the Godot import cache checkpointed between runs.

### Size budget

The ~250 MB APK is dominated by uncompressed PCM ambience (crowd home/away, chants,
goal roar ≈ 200 MB generated WAV) plus VRAM-compressed (ETC2/ASTC) textures and the
arm64 engine (~50 MB). The exact byte count of the current release APK is stated in
the release notes.

## Project structure

```
src/core/      match state machine, ball physics, formations, AI, referee, teams
src/render/    procedural stadium builder, grass shader, player bodies, replay
src/ui/        HUD, touch controls, menu
src/audio/     crowd ambience mixer with excitement swells
tests/         headless engine tests
tools/         asset generator (Python), screenshot/perf capture
```
